# PRD: Dynamic Greeting Feature

## Introduction

Add a dynamic greeting feature to `app.sh` that displays a time-based greeting (morning/afternoon/evening) when the script is run.

## Goals

- Display greeting based on current time of day
- Show user name in greeting if available from environment
- Graceful fallback when user cannot be determined

## User Stories

### US-001: Time-based greeting
**Description:** As a user, I want to see a greeting that reflects the time of day.

**Acceptance Criteria:**
- [ ] Script shows "Good morning" from 5:00 AM to 11:59 AM
- [ ] Script shows "Good afternoon" from 12:00 PM to 4:59 PM
- [ ] Script shows "Good evening" from 5:00 PM to 4:59 AM
- [ ] Greeting displays correctly in terminal

### US-002: Personalized greeting
**Description:** As a user, I want to see my name in the greeting.

**Acceptance Criteria:**
- [ ] Use USER or USERNAME environment variable if set
- [ ] Fallback to "User" when no user variable is available
- [ ] Greeting includes both time-based and name components

### US-003: Interactive name option
**Description:** As a user, I want to specify my name via command line.

**Acceptance Criteria:**
- [ ] Script accepts name as optional argument
- [ ] Command line name takes precedence over environment variable

## Functional Requirements

- FR-1: Determine time of day using `date` command
- FR-2: Display appropriate greeting based on hour (0-23)
- FR-3: Detect user from USER or USERNAME env var
- FR-4: Accept optional name argument: `./app.sh [name]`
- FR-5: Format: "[Greeting], [name]!"

## Non-Goals

- No persistent user configuration
- No interactive prompts for input
- No color/formatting in greeting

## Technical Considerations

- Use bash built-in or POSIX-compatible date formatting
- No external dependencies beyond standard POSIX tools

## Success Metrics

- Greeting displays correctly for all hours
- User can override name via argument
